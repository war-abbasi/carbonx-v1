API ENDPOINTS (8 endpoints)
================================================================================

  ✓ GET  /health
      Purpose: Service health check
      Response: {"status": "available"}

  ✓ POST /api/v1/forecast/generate
      Purpose: Generate 12-month forecast (all 3 models)
      Input: org_id, historical_data, months_ahead, features
      Output: Forecasts from all 3 models + best model selection

  ✓ GET  /api/v1/forecast/<org_id>
      Purpose: Retrieve latest forecast
      Output: Previous forecast result

  ✓ POST /api/v1/emissions/calculate
      Purpose: Calculate Scope 1/2/3 from activities
      Input: activities (electricity, diesel, travel, waste)
      Output: scope1, scope2, scope3, total_co2e

  ✓ GET  /api/v1/dashboard/<org_id>
      Purpose: Dashboard summary
      Output: Current emissions + trend + forecast

  ✓ GET  /api/v1/models/comparison
      Purpose: Get model metrics comparison table
      Output: RMSE, MAE, MAPE, R² for all models

  ✓ POST /api/v1/activity/upload
      Purpose: Bulk upload activity records
      Input: List of activity records
      Output: Validation results + errors

  ✓ POST /api/v1/models/train
      Purpose: Trigger model retraining
      Output: Training status
